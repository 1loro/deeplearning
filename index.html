CNN Simpsons — Evaluación Parcial N°2

1 Términos que debes saber
CNN (Red Neuronal Convolucional)
Arquitectura de red neuronal diseñada para procesar datos con estructura de grilla (imágenes). Aprende jerarquías visuales mediante filtros convolucionales.
Conv2D
Capa convolucional 2D. Aplica filtros sobre la imagen para detectar bordes, texturas, y luego formas complejas en capas más profundas.
BatchNormalization (BN)
Normaliza las activaciones de cada mini-batch. Estabiliza y acelera el entrenamiento, reduciendo la dependencia de la inicialización.
MaxPooling / GlobalAveragePooling
Reducen dimensionalidad espacial. MaxPooling toma el valor máximo; GlobalAveragePooling promedia toda la feature map → un solo valor por canal.
Dropout
Desactiva neuronas aleatoriamente durante el entrenamiento. Técnica de regularización que previene el overfitting.
Softmax
Función de activación de la capa final para clasificación multiclase. Convierte logits en probabilidades que suman 1.0.
Skip Connections (conexiones residuales)
Conexiones que "saltan" una o más capas y suman la entrada directamente a la salida del bloque. Clave en ResNet.
Degradation Problem
En redes muy profundas sin skip connections, el accuracy empeora al agregar capas. PlainNet lo sufre; ResNet lo resuelve.
Overfitting / Sobreentrenamiento
Cuando el modelo memoriza el set de entrenamiento y falla en datos nuevos. Se evidencia con baja brecha train-val en accuracy.
Data Augmentation
Generar variaciones artificiales de las imágenes de entrenamiento (rotación, flip, zoom) para aumentar la diversidad sin obtener más datos reales.
Accuracy
Proporción de predicciones correctas sobre el total. Métrica global del modelo.
F1-Score (Macro / Weighted)
Media harmónica de Precision y Recall. Macro: promedio sin ponderar por clase. Weighted: ponderado por soporte de cada clase.
Precision y Recall
Precision: de los que predije como X, ¿cuántos son X? Recall: de todos los X reales, ¿cuántos detecté?
Confusion Matrix (Matriz de Confusión)
Tabla que muestra predicciones vs. etiquetas reales por clase. Normalizada, muestra el recall por clase (diagonal = aciertos).
Adam Optimizer
Optimizador de gradiente adaptivo. Ajusta la tasa de aprendizaje por parámetro usando momentum y RMS. Más eficiente que SGD estándar.
Learning Rate (lr)
Tamaño del paso en cada actualización de pesos. Muy alto → inestable; muy bajo → convergencia lenta.
Categorical Cross-Entropy
Función de pérdida para clasificación multiclase con one-hot encoding. Penaliza predicciones con baja probabilidad en la clase correcta.
EarlyStopping
Detiene el entrenamiento si una métrica monitoreada (ej. val_loss) no mejora después de N épocas (patience). Evita sobreentrenamiento.
ReduceLROnPlateau
Callback que reduce el learning rate por un factor cuando la métrica se estanca. Permite ajuste fino automático.
ImageDataGenerator
Clase de Keras que genera augmentations en tiempo real durante el entrenamiento, sin necesidad de guardar imágenes adicionales en disco.
Transfer Learning
Usar un modelo preentrenado (ej. EfficientNet) como punto de partida. Reutiliza características aprendidas en grandes datasets. Mencionado como mejora futura.
One-hot encoding
Representar la clase como vector binario donde solo el índice correcto es 1. Necesario para categorical cross-entropy.
Batch Size
Número de ejemplos procesados por iteración antes de actualizar los pesos. Afecta la estabilidad del gradiente y velocidad.
Epoch
Una pasada completa por todo el dataset de entrenamiento. Se usan múltiples épocas para que el modelo aprenda iterativamente.
2 Herramientas — ¿por qué cada una?
¿Por qué TensorFlow / Keras?
API de alto nivel que simplifica la construcción de modelos. Tiene integración nativa con GPU en Google Colab y capas predefinidas (Conv2D, BatchNorm, etc.) listas para usar.
❌ No PyTorch: ambos son válidos, pero Keras ofrece una API más simple y rápida de prototipar para este proyecto.
¿Por qué OpenCV (cv2)?
Librería estándar para lectura y resize eficiente de imágenes en batch. Optimizada para operaciones de visión computacional en memoria.
❌ No PIL/Pillow puro: cv2 es más eficiente para procesar grandes volúmenes de imágenes (~20k imágenes).
¿Por qué scikit-learn?
Provee las métricas de evaluación necesarias: accuracy_score, f1_score, precision, recall, confusion_matrix. No se usa para entrenar el modelo, solo para medirlo.
❌ No calcular manualmente: sklearn tiene implementaciones probadas y con soporte para multiclase.
¿Por qué ImageDataGenerator?
Aplica data augmentation en tiempo real durante el entrenamiento. No requiere guardar imágenes adicionales en disco; las transformaciones se generan al vuelo.
❌ No augmentar offline: ocuparía mucho más almacenamiento y tiempo de preprocesamiento sin beneficio adicional.
3 Arquitecturas CNN — Comparación
CNN Propia
  • 3 bloques: Conv → BN → Pool → Dropout
  • Filtros: 32 → 64 → 128
  • Capa densa: 256 → 18 (softmax)
✦ Diseño compacto, fácil de interpretar. Sirve como baseline propio para comparar.
Plain Net
  • 4 bloques convolucionales profundos
  • Filtros: 64 → 64 → 128 → 128
  • GlobalAveragePooling al final
  • Sin skip connections
✦ Demuestra el degradation problem: agregar profundidad sin skip connections no siempre mejora.
ResNet-style ⭐
  • Bloques residuales con skip connections
  • Filtros: 32 → 64 → 128 → 256
  • GlobalAveragePooling al final
✦ Mejor rendimiento. Skip connections permiten flujo directo de gradientes, resolviendo el degradation problem. Estado del arte.

4 Hiperparámetros — valor y justificación
Hiperparámetro Valor ¿Por qué este valor?
Optimizer Adam Ajuste adaptivo del lr por parámetro. Converge más rápido que SGD estándar. El estándar de facto en deep learning.
Learning Rate 0.001 Valor por defecto recomendado para Adam. Balance entre velocidad de convergencia y estabilidad. Se compara también 0.0005.
Batch Size 64 Balance entre velocidad de GPU y estabilidad del gradiente. Muy pequeño = ruido; muy grande = menos generalización.
Loss Function Categorical CE Correcta para clasificación multiclase con one-hot encoding. Penaliza predicciones incorrectas con alta confianza.
Épocas máx. 50 + EarlyStopping El límite de 50 evita entrenamientos eternos. EarlyStopping con patience=8 detiene si no mejora, evitando sobreentrenamiento.
ReduceLROnPlateau factor=0.5, patience=4 Reduce el lr a la mitad cuando el entrenamiento se estanca por 4 épocas. Permite ajuste fino automático sin intervención manual.
5 Data Augmentation — técnica y razón
Rotación ±15°
Los personajes pueden aparecer levemente inclinados en las escenas de la serie.
Flip horizontal
Aumenta variabilidad sin alterar la identidad del personaje (un Bart volteado sigue siendo Bart).
Zoom ±10%
Simula distintas escalas de captura dentro de un mismo encuadre.
Desplazamiento ±10%
El personaje no siempre aparece perfectamente centrado en la imagen.
Shear ±10°
Variaciones leves de perspectiva propias de la animación 2D de la serie.
Brillo ×0.8–1.2
Variabilidad de iluminación entre distintos episodios o escenas.
¿Por qué augmentation en tiempo real y no offline?
Genera variaciones únicas por época, maximizando la diversidad que ve el modelo. No ocupa espacio extra en disco. ImageDataGenerator lo hace automáticamente con Keras.
6 Preguntas que te pueden hacer — y cómo responderlas
❓
¿Por qué usar CNNs y no una red densa (MLP)?
Las CNNs capturan jerarquías visuales locales (bordes → texturas → formas → objetos) mediante filtros compartidos. Una red densa trataría cada píxel independientemente, perdiendo estructura espacial y requiriendo millones de parámetros para el mismo resultado.
❓
¿Qué resuelven las skip connections de ResNet?
El degradation problem: en redes profundas, los gradientes pueden desvanecerse o distorsionarse (vanishing gradient). Las skip connections crean un camino directo para el flujo de gradientes, permitiendo entrenar redes más profundas sin pérdida de rendimiento.
❓
¿Por qué PlainNet no supera a ResNet aunque es más profunda?
Sufre el degradation problem. Sin skip connections, agregar más capas no garantiza mejor rendimiento — de hecho puede empeorarlo. ResNet con skip connections resuelve esto y justifica su mayor accuracy y F1.
❓
¿Qué mide la matriz de confusión normalizada?
Muestra el recall por clase en la diagonal: qué fracción de los ejemplos reales de cada clase fueron correctamente predichos. Las clases con baja diagonal (bajo recall) son las que el modelo confunde más — candidatas a mejoras con balanceo de clases o augmentation específico.
❓
¿Por qué usar categorical cross-entropy y no MSE?
MSE (error cuadrático) no está diseñada para clasificación. Categorical CE penaliza correctamente cuando el modelo asigna baja probabilidad a la clase correcta, y funciona bien con softmax en problemas multiclase.
❓
¿Cómo se seleccionó el modelo final?
Por 4 criterios combinados: mayor accuracy y F1 en test set, menor brecha train-val (mejor generalización), estabilidad en curvas de entrenamiento, y buena relación rendimiento/parámetros. Ganó ResNet-style con lr óptimo y augmentation completo.
❓
¿Qué es GlobalAveragePooling y por qué usarlo?
Promedia cada feature map completa a un único valor. Reemplaza a Flatten+Dense, reduce drásticamente los parámetros, y actúa como regularizador natural al eliminar conexiones redundantes. Más robusto ante overfitting.
